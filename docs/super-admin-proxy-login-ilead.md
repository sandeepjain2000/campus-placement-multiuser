# Super Admin proxy login — Ilead student upload

Operational steps after deploy (no separate Super Admin CSV path).

1. Sign in as Super Admin.
2. Open **Manage Colleges** (`/dashboard/admin/colleges`).
3. Find **Ilead** (or open the college profile) and click **Login as**.
4. Confirm the amber banner: “Working as … / Exit to Super Admin”.
5. Open **Students** → bulk upload. Map the college sheet to the export template headers if needed, then upload.
6. Click **Exit to Super Admin** when finished.

Password / account email changes are blocked while proxying. Start and end are written to audit logs.
