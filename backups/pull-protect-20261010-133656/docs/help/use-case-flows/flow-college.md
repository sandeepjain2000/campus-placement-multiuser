# College admin (TPO) — run the season

> **Section:** Use case flows  
> **Source:** help  
> **Audience:** all

Goal: keep employers and students aligned, enforce Placement Rules, and leave an auditable trail for leadership.

Step-by-step
1. Open Settings: set season label, branding, academic taxonomy, FCFS, offer limits, and acceptance windows as your product exposes them.
2. Employers → Partnership Requests: approve companies that should hire on campus; reject or follow up on others.
3. Share the Enrollment key only through official channels. Rotate it if it leaks. Help students who fail registration with an expired key.
4. Students: verify profiles and, when required, verify CVs on student detail so apply gates unlock.
5. Placement Drives: process Unapproved (requested) drives—approve (confirm calendar clash warnings; use force only deliberately) or reject. Internships: approve/reject listing visibility so students see only published + approved items.
6. During selection: use Hiring Assessment (read-only), Interview Scheduling, Applications, and Offers. Bulk offer CSV is on the Offers page, not a separate sidebar item.
7. Communications: Message templates (preview with sample data; restore system email versions when offered), Bulk notifications, Clarifications, Discussions, Feature Ideas.
8. Calendar / Events / Guest engagements keep visit days visible. Reports and Audit reports close the loop.

Tip: Placement committee users can watch Students/Applications but cannot perform TPO approvals—keep that boundary clear in your office.
