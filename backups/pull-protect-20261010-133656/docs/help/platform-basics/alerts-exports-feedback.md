# Alerts, exports, and feedback

> **Section:** Platform basics  
> **Source:** help  
> **Audience:** all

Alerts
Open the bell (or Alerts in the menu) for time-sensitive messages: partnership updates, interview slots, offer notifications, and similar events. Clear or act on items regularly so deadlines are not missed. Alerts are role-specific—you only see what applies to your account.

Help
Use the sparkle / Help control to browse these articles or ask a natural-language question. Answers come from indexed help docs and developer QA notes. After major documentation updates, operators run: npm run qa:sync-help-knowledge (OPENAI_API_KEY improves semantic search).

My data export
Request a downloadable copy of your data where the product supports self-service export (privacy / GDPR-style). Follow on-screen instructions; generation may take a short time. Some exports download in the browser only and are not emailed unless a separate mail feature says so.

Feedback
Use Feedback (or Feedback inbox for admins) to report bugs, UX friction, or ideas. Include role, page URL, and approximate time. College and super-admin teams may triage separate inboxes.

Tip: for “something is broken,” pair Feedback with a screenshot and whether the issue is reproducible after refresh.
