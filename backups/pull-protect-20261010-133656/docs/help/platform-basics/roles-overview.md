# Roles at a glance

> **Section:** Platform basics  
> **Source:** help  
> **Audience:** all

Student
Apply to campus drives and programs, maintain My Profile / Documents / My CVs, track applications, interviews, and offers, read clarifications, and join discussions where enabled. Alumni students typically use alumni job menus instead of campus drives and internships. After accepting a placement offer, a placement lock may block further drive/job applies.

Employer
Maintain Company Profile, request Campus Partnerships, set an Active campus, create jobs/drives/internships, run Assessment uploads or Assessment Update Online, schedule interviews, manage Applications and Offers (plus Offer Templates), watch Shortlisted / Unavailable (FCFS), and use Marketplace, sponsorships, guest needs, and mentorship volunteering where enabled.

College admin (TPO)
Approve employer partnerships and drive/internship visibility, verify students and CVs, manage the enrollment key, monitor Applications and Offers, publish clarifications and bulk notifications, maintain message templates (and restore system email versions when available), set Placement Rules (including FCFS and offer limits), run calendars/events, and use Reports / Feature Ideas / Marketplace.

Placement committee
Read-only awareness for the same college: typically Overview, Students, Applications, plus shared Alerts and Feedback. Cannot approve employers or drives, edit rules, create offers, or change Settings. Ask the TPO for actions you cannot perform.

Super admin
Operate the whole platform: Colleges, Employers, pending registrations, Users, platform Email templates and Email logs, Marketplace catalog, Feedback, audit/error logs, and Settings (outbound email / ZeptoMail, Test environment redirect, storage, flags).

Tip: if menus look wrong after a role change, sign out and sign in again so the session refreshes.
