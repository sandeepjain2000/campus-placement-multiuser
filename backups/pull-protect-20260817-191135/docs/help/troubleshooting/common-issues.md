# Common issues

> **Section:** Troubleshooting  
> **Source:** help  
> **Audience:** all

Cannot apply to a drive
Check: application deadline; drive open status (approved/scheduled); CGPA/branch/batch eligibility; profile verified; My CVs verified if required; not already applied; no placement lock after accepting an offer.

Internship apply blocked after Select elsewhere
FCFS / single selected internship rule. You already hold a selected internship; other applies are blocked until rules/process release you.

Employer sees no campus / empty student export
Partnership not approved, or Active campus wrong, or college has not approved the drive/listing visibility.

Assessment CSV rejected
Re-export fresh file; do not alter id columns; use allowed hiring_result values only; ensure roll numbers exist on campus. Assessment map is not required for hiring_result upload. Fix rows on the import review screen before Accept.

Student appears on Unavailable (FCFS)
Another employer already Select’d on that track. Coordinate with the college; do not expect a second Select to succeed.

Offers CSV not in sidebar
Open Offers and use the upload link on that page.

Student cannot accept offer
Offer not pending (already accepted/rejected/revoked/expired); past deadline (410); max offers reached; or acceptance window after first accept expired.

Emails arrive only in test inboxes
Super Admin Test environment = Yes and/or OUTBOUND_EMAIL_OVERRIDE is set. Turn off for real recipients and confirm in Email logs.

Page blank or data missing
Hard refresh; retry once; note time and URL. Persistent failures may be maintenance or a platform error—use Feedback or error-log channels.

Still stuck
Feedback with role, URL, approximate time, and exact error text—or contact your TPO / platform support. Include whether the issue reproduces in a private browser window.
