# Student registration (campus key)

> **Section:** Accounts & registration  
> **Source:** help  
> **Audience:** all

How students join
Registration uses the campus enrollment key issued by the placement office—not the roll number as the secret. Keys are long opaque strings; paste carefully (leading/trailing spaces are usually ignored).

What you enter
Institute email, enrollment key, department, roll number, batch year, and other fields your college requires. Password rules appear on the form.

If registration fails
• Key expired or rotated—ask TPO for the current key.
• Email already registered—sign in or use forgot password; do not create duplicates.
• College not ready—super admin may still need to activate the college tenant.
• Typo in department/batch—match institute master data.

After success
Sign in, complete profile, upload CV/documents, and wait for verification if required before applying.

Tip: TPOs should distribute keys through official LMS/email only, never public social posts.
