# Sessions and sign-out

> **Section:** Accounts & registration  
> **Source:** help  
> **Audience:** all

Session lifetime
Sessions expire after inactivity for security. You will be sent to login when the session ends. Save form work frequently on long pages (assessment grids, bulk edits).

Shared computers
Always Sign out from the top bar when finished. Do not stay signed in on lab machines.

Role or permission changes
If an admin changes your role (e.g. committee → college admin), sign out and sign in so menus and API authorization refresh.

Password changes
Use account security flows provided by your deployment (change password / forgot password). After reset, old sessions may end.

Tip: if you bounce between two roles’ homes unexpectedly, clear the site session and sign in with the intended account only.
