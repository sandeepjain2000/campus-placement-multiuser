# Assessment CSV workflow (step by step)

> **Section:** Employers  
> **Source:** help  
> **Audience:** employer

Use this path when many students need a hiring_result in one pass.

Preparation
• Active campus is correct and partnership approved.
• Drive/job/internship target exists and students have applied (or you are scoring the full campus list as designed).

Steps
1. Open Assessment uploads (CSV) or Assessment Update Online. Pick the tab: Internship, Jobs, Drive, or Projects.
2. Select campus and the specific drive/job target.
3. Click Export CSV. Expect columns such as system_id, college_roll_no, placement_drive_id, job_id, tenant_id, candidate_name, hiring_result, remarks (exact set may evolve—always use a fresh export).
4. Offline, set hiring_result only to allowed values: Shortlist, Reject, Select, Decline, Withdraw. Leave blank for no decision. Keep ids intact.
5. Upload the CSV. If validation fails, correct rows on the import review screen, then Accept. Clean files may import immediately.
6. When the round is final, Submit results. After submit, CSV/online paths cannot change hiring_result for that submission.
7. Verify on Hiring Results Dashboard. The college mirror is Hiring Assessment (read-only).

Online alternative
Set hiring_result in the browser grid and Save. You can mix CSV and online before submit; both feed the dashboard.

Side effects
• Assessment updates do not email students automatically.
• Select may mark the student Unavailable (FCFS) for other employers on that track.
• Withdrawn applications generally cannot be updated.

Tip: never hand-edit id columns; re-export if the roster changed.
